# 使用说明

## 两个版本，选一个用

| 文件 | 说明 |
|---|---|
| **`src/去色带-单文件.bat`** | **推荐**。一个文件搞定，双击即用，自带文件选择框 |
| `src/去色带.bat` + `src/去色带.ps1` | 两个文件必须放一起；功能完全一样，逻辑拆在 ps1 里 |

两个版本参数一致、输出速度一致，随便用哪个。

---

## 前置条件

需要一个 **ffmpeg full build**（要带 `libx265`、`libx264`、`zscale`），推荐 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 的版本。

脚本会先找系统 PATH 里的 `ffmpeg.exe`；找不到就报错并提示你改路径：

- 单文件版：记事本打开，找开头的 `set "FF=ffmpeg"`
- ps1 版：找 `Find-Ffmpeg` 函数里的 `$cands`

---

## 用法（三步，不用拖拽）

1. **双击** `去色带-单文件.bat`
2. 在弹出的窗口里**选中视频文件** → 打开
3. 输入模式号回车

然后就等，窗口里会一直刷进度（`fps` 是每秒帧数，`speed=0.15x` 表示 1 秒处理完 0.15 秒视频）。

> 中途别关窗口。关了 = 中断，输出文件不完整。

把视频**拖到 bat 图标上**也可以，效果一样。

---

## 五种模式

| | 模式 | 画质 | 1440p60 耗时 | 体积参考 | 什么时候用 |
|---|---|---|---|---|---|
| **1** | 10-bit HEVC 母版 | 最好 | 15–20 分钟 | 约 1.4 GB（2.6 分钟片） | 自己看、收藏 |
| **2** | 8-bit H.264 兼容版 | 亮度改善，色度治不了 | 3–5 分钟 | 约 440 MB | 剪辑、上传、手机 |
| **3** | 20 秒样片 | 同模式 1 | 约 2 分钟 | 约 180 MB | 先看效果 |
| **4** | 硬件加速（NVENC） | 接近模式 1 | **约 3 分钟** | 约 500 MB | 赶时间、批量 |
| **5** | HLG HDR | 同模式 1，走 HDR 通路 | 15–20 分钟 | 约 670 MB | 杜比视界 / HDR 屏 |

**模式 2 治不了色度色带**：8-bit 4:2:0 的色度总共只有二三十个量化级，去色带补出来的中间色阶存不进去。这是格式的物理限制。

**怎么挑**：HDR 屏且主要在 HDR 环境下看 → 模式 5；普通屏 → 模式 1；要上传/剪辑 → 模式 2。

---

## 输出在哪

**和源文件在同一个文件夹**：

```
原文件：  input.mp4
模式 1：  input (deband).mp4
模式 2：  input (deband 8bit).mp4
模式 3：  input (deband 样片).mp4
模式 4：  input (deband 硬件).mp4
模式 5：  input (deband HLG).mp4
```

**不会覆盖源文件**。同名文件已存在时自动加编号：`(deband 2).mp4`。

## 命令行 / 批量

模式号写在第二个参数上，跳过所有交互：

```bat
去色带-单文件.bat "D:\视频\abc.mp4" 1
```

批量：

```bat
@echo off
for %%f in ("D:\video\*.mp4") do (
    call "去色带-单文件.bat" "%%~ff" 2
)
echo 全部完成
pause
```

> ⚠️ 先算时间：模式 2 每个 2.6 分钟的视频约 4 分钟，70 个就是 4–5 小时。
> ⚠️ 别让通配符重复匹配已处理过的文件，否则会把 `(deband).mp4` 再处理一遍。

## 想调参数

单文件版开头：

```bat
set "VF1=format=yuv420p10le,deband=1thr=0.065:2thr=0.065:3thr=0.065:range=28:blur=0:coupling=0"
```

| 参数 | 现在 | 调大会怎样 | 调小会怎样 |
|---|---|---|---|
| `1thr`…`4thr` | `0.065` | 更彻底，但可能抹细节、冒噪点 | 留残带 |
| `range` | `28` | 吃掉更宽的台阶 | 只处理细台阶 |
| `blur` | `0` | **改回 1 画面立刻发「脏」** | — |
| `coupling` | `0` | **改回 1 色度失效** | — |

其他常用：

| 想要 | 改哪里 |
|---|---|
| 文件更小 | `-crf 17` → `21` |
| 更保真 | `-crf 17` → `15` |
| 编码更快 | `-preset medium` → `fast` |

改完先跑模式 3 出样片看效果，别直接跑整片。

## 常见问题

**Q：双击后一闪就没了？**
在该文件夹地址栏输入 `cmd` 回车，再敲 bat 文件名运行，就能看到错误信息。

**Q：提示「找不到 ffmpeg.exe」？**
按上面「前置条件」改路径。

**Q：输出文件打不开 / 播放器说缺编解码器？**
用模式 2（H.264 8-bit，Windows 自带解码器），或装 VLC / mpv。

**Q：Windows 开了 HDR 后，10-bit 母版画面发黑、只剩高光，8-bit 版却正常？**
文件没问题（色彩标记在容器和码流里都写全了，BT.709 + tv range，无 HDR 元数据）。是播放器把 10-bit 当成 HDR10 解码了——PotPlayer 就会这样。

解法：在播放器里关掉 HDR 处理（PotPlayer：`F5` → 视频 → 处理，把带 HDR 的项都设成「不使用」），或者直接看模式 2 / 模式 5。

**Q：模式 4 报错、提示没有 hevc_nvenc？**
没有 NVIDIA 显卡，或驱动太老。改用模式 1。

**Q：能不能降噪？**
对数字直录的素材不要。实测平面区噪声 σ=0、时域也是 0，降噪只会让色带台阶变宽（3.8 → 4.1 px）并损失 4% 细节。
